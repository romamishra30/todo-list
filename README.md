# To-Do List

A simple and responsive To-Do List web app that helps users organize daily tasks with priority levels, search, filters, progress tracking, and local storage support.

## Features

- Add new tasks
- Set task priority: Low, Medium, High
- Add due dates
- Mark tasks as completed
- Edit and delete tasks
- Search tasks
- Filter tasks by All, Active, and Completed
- Progress bar for completed tasks
- Clear completed tasks
- Saves tasks using local storage

## Tech Stack

- HTML
- CSS
- JavaScript

## How to Use

1. Enter a task name.
2. Select priority.
3. Choose a due date.
4. Click **Add**.
5. Use filters to view all, active, or completed tasks.
